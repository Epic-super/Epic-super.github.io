首次配置清单（API Key 与成本说明）

① 文案 LLM：推荐 DeepSeek 开放平台（每百万 token 几元，一条视频用量可忽略）；也支持 OpenAI / Kimi / 通义千问 / 本地 Ollama 等。

② 视频素材：Pexels API 免费申请 Key，Pixabay / Coverr 同理；也可接 WaveSpeed、火山 Seedance 生成式素材（按量付费，可选）。

③ 配音 TTS：默认 Edge TTS（WebUI 内显示为 Azure TTS V1）免费、无需 Key；需要音色克隆再配 Azure V2 / ElevenLabs 等。

④ 配置文件：首次启动自动在项目根目录生成 config.toml（源自 config.example.toml），WebUI 设置页可直接改；ffmpeg 一般自动下载。

成本结论：DeepSeek + Edge TTS + Pexels 全免费/极低价组合，一条成品片边际成本 ≈ 几分钱。
