如何把这块嵌进别的页面？

本页是自包含单文件，不依赖任何外部资源。两种集成方式：

① 直接 iframe 嵌入（推荐，自动高度自适应 + 主题同步）

<iframe src="noclock.html" id="noclockFrame"
  style="width:100%;border:0;background:transparent"></iframe>
<script>
  // 父页监听：自动撑高 iframe
  window.addEventListener('message', e=>{
    if(e.data && e.data.type==='noclock-resize'){
      document.getElementById('noclockFrame').style.height = e.data.height + 'px';
    }
  });
  // 可选：向模块同步主题（'light' | 'dark'）
  // frame.contentWindow.postMessage({type:'noclock-theme',theme:'dark'}, '*');
</script>

② 复制区块嵌入

把 noclock.html 的内容整体拷进目标页，
或直接 <link>/<style> + <script> 拆分引用。
模块通过 postMessage 与父页通信，无需额外配置。
