苍穹降临 · 精准解析 + 复原完整性

TRAE 2026 航空相邻作品 · 社会服务赛道 · 三维城市空中交通推演沙盒 · 源码公开
作品一句话：一个单文件网页，用 Three.js 渲染 300 架未来城市飞行器，对比「无调度自由飞行」与「苍穹智能调度」两种状态的碰撞/秩序差异，用实时数据面板证明"空中交通秩序"的价值。
关键事实：作者把完整源码直接贴进帖子，"复制保存为 苍穹降临.html 双击即可运行"。这是本次航空相邻四件里复刻确定性最高的一件——近乎"运行作者源码"。
一、技术架构

渲染层

Three.js + WebGL。WebGLRenderer（桌面端开 antialias）
PerspectiveCamera(55, aspect, 0.1, 600) 位于 (58,46,58)
飞行器用 InstancedMesh（合并几何体 mergeGeometries）批量渲染 300 架；城市 100 个 BoxGeometry 建筑（80 随机 + 20 环形），MeshPhongMaterial 半透明蓝。

数据层

NP=300 架飞行器，三维坐标 (x,y,z)。
飞行高度带 FY0=8 → FY1=35。
基础速度 speed=0.15+rand*0.35，混沌放大 SMUL=18。
状态字段：vx/vy/vz, falling, dead, layer, oA(角), oAV(角速度), oR/oY(航道半径/高度), bright 等。

视角交互OrbitControls：拖拽旋转、滚轮缩放（minDistance=25, maxDistance=150, maxPolarAngle=PI*0.48），真 3D 透视。移动端 touch-action:none 支持触控。
二、两套状态机（核心逻辑）

① 混沌推演 mode='chaos' · 无调度自由飞行

运动生成updateChaos：每帧加随机扰动 vx += (rand-0.5)*s*0.15；限速 mx=speed*SMUL*1.8；边界 bd=FR+15=45 软回弹；高度约束 y<FY0 上 / y>FY1+5 下。
碰撞判定空间哈希 CELL=6，邻域 3×3×3 搜索；两机 dist < CD(2.0) 且 >0.01 → 互相排斥 + spawnFlash 闪点 + colCount++ + 标记 bright=0.3。
建筑坠毁hitBuilding(a)：建筑 blds 含 hw,hd,hh，若 |x-b.x|<hw && |z-b.z|<hd && y∈(0,hh) → falling=true；坠落 vy -= GRAV(1.2)*dt，y<=0 则 dead 后重生。
// updateChaos 片段（还原逻辑）
a.vx += (Math.random()-0.5)*s*0.15;
if(a.vx > mx) a.vx = mx;  // mx = speed*SMUL*1.8
if(Math.abs(a.x) > bd) a.vx -= Math.sign(a.x)*...; // 软回弹 bd=45
if(dist < CD) { repel(); colCount++; spawnFlash(); } // CD=2.0

② 苍穹调度 mode='transit' → 'order' · 三层有序航道

三层航道每层 100 架，反向交替 dir：
层1 {y:12, r:18, n:100, dir: 1}
层2 {y:21.5,r:24, n:100, dir:-1}
层3 {y:31, r:30, n:100, dir: 1}
激活与过渡点「苍穹降临」→ mode='transit'，扩展光圈 ringMesh 缩放 transT*40；transT>3 切 mode='order'，分配 oR/oY/oAV/oA；过渡期速度指数衰减、材质转蓝 acBlue。
秩序运动updateOrder：每机 oA += oAV*dt 绕圈，目标点 (cos(oA)*oR, oY, sin(oA)*oR)，线性插值 lerp=1-pow(0.02,dt) 逼近。分层 + 不同半径/方向 → 天然零碰撞。
// updateOrder 片段
a.oA += a.oAV*dt;
const tx=Math.cos(a.oA)*a.oR, tz=Math.sin(a.oA)*a.oR;
a.x += (tx-a.x)*(1-Math.pow(0.02,dt));
a.z += (tz-a.z)*(1-Math.pow(0.02,dt)); // 逼近圆轨，零碰撞
三、实时数据面板
显示DOM #stats：碰撞次数: X | 风险率: Y%。
碰撞次数colCount，混沌每次碰撞 +1，初始 0。
实时风险率calcRisk：仅 chaos/transit 计算，每 0.5s 采样；步长 step=max(1,floor(NP/RS))（RS=60→step=5），邻域 dist<RT(14) 计数 close；公式 risk=min(100, close/total*150)；秩序模式 risk 衰减至 0。
四、复原完整性评估

软件复原度：~97%（运行作者源码）/ ~92%（独立重写）

源码已公开 + 单文件 + 纯前端无后端无数据库，没有任何"真实工业数据/物理硬件"依赖。这意味着复刻瓶颈几乎只有一项：Three.js 的加载方式。

A. 直接运行作者源码~97%
作者已贴完整 HTML。唯一缺口：源码用 ES module import * as THREE from 'three' + addons（OrbitControls/mergeGeometries），浏览器双击需 importmap 指向 three CDN 或本地 three 包。① 联网：加 importmap 即可跑；② 离线：需把 three.module.js + 两个 addon 下载到本地并改路径。功能 100% 一致，仅部署方式需适配。
B. 独立重写等效实现~92%
渲染（InstancedMesh 批量）、物理（空间哈希碰撞 + 软回弹）、建筑坠毁（重力）、三层航道调度（圆轨插值）、风险采样（邻域计数公式）——全部逻辑清晰、数值明确、可逆。重写的"功能等效版"可达 ~92%，缺口在视觉细节打磨（闪点/光圈/材质过渡）与极端性能优化。
C. 工程真实度（相对真实 UAM 空管）~15%
它是概念可视化论证（作者原话"为三维交通纪元写下第一部交通宪法的可视化证明"），不是真实空管系统：无真实飞行力学（升力/阻力）、无真实空域结构、无真实交通流 OD、无适航/间隔标准（如 FAA UAM ConOps）。这一点作者定位即如此，原文也没做。所以"复刻这个作品"极易，"复刻真实航空交通管理"它本就不是。
