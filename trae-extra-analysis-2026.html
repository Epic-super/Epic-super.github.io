01 词元开物 IterxAI — 冠军 · 30万

杨振宇(硬件)/郑仲鹏(工业设计)/鹿诚龙(软件)，深圳科创学院，全职创业者

完整链路（精准）

自然语言一句话 → 确认需求 → 生成 PRD → 元件选型 → 引脚连接 → 代码生成 + 编译/烧录/仿真 → 确认能跑 → PCB Layout 自动布线 → 生成加工文件 → 发给桌面雕刻机 → 雕出真实电路板。

  • 稳定复现关键：建元件库规范，AI 不再"猜"；编译失败能判断是代码/依赖/开发板配置问题。
  • 初赛局限：链路跑通但更像"条件都对时能工作的 Demo"；复赛暴露选板难、缺引脚、仿真能跑实物接不上、换电脑环境崩等问题并死磕解决。
  • 现场演示：会"跑"的手机智能底座、双轮驱动气球人。
75%
复现概率：软件 IDE 层 ~75% / 端到端含物理雕刻 ~25%IDE 前端 + 调用 KiCad 等开源 EDA 做 Layout/布线/出 G-code 可复刻；但"雕出真实板"需真实 CNC 雕刻机（我们无设备）。无硬件则链路止于 G-code 文件。
价值：概念价值极高——戳中 AI Coding 从软件走向硬件的断点，商业化潜力大（硬件创客教育/降门槛）。复刻价值在于做出"AI 硬件 IDE"原型演示；缺真实 EDA 集成与雕刻硬件时，只是流程演示而非造物。

03 听到鸟 HEARDIT — 硬件交互赛道大奖 · 5万

听到鸟 / HEARDIT硬件交互赛道大奖 · 5万科技/消费电子（助听）· PWA Web App
Web Audio 真实可跑 无后端/离线 非医疗替代
作者
Shaker，失业 1 月的汽车 HMI/UI 设计师，0.25 年 vibe coding
迭代
27 天 170+ 版本；复赛 120+ 版
形态
PWA，手机浏览器即用，离线可用，无后端
实测
轻/中度有效；测试耳机 PDD ¥6.9 有线耳机

五阶段信号链（精准）

麦克风 → 前置滤波 → 六频段 WDRC 压缩(+EQ) → NAL-NL2 听力补偿(双耳独立测听) → 啸叫防护(自适应陷波+反馈延迟三级) → 安全限幅 → 耳机。端到端 <15ms。

  • 真实度：Web Audio API 实时音频处理真能跑；WDRC/NAL-NL2 是真实助听算法（有公开公式/文献）。
  • 边界清晰：不替代专业助听器，覆盖因经济/操作/心理门槛"什么都不做"的轻中度与临时需求。
  • 开源：作者承诺近期发开源贴公开全部源码（当前未开源）。
概率
90%
复现概率：~90%纯前端 Web Audio，无硬件依赖（任意有线耳机+手机麦克风）。信号链各环节为可复刻标准 DSP（BiquadFilter/AudioWorklet + WDRC/NAL-NL2 公开算法）。缺口在算法精度调优需声学专业知识，但功能框架可完整复刻。
价值：社会价值高（助老/低成本助听），公益属性强，已承诺开源。复刻价值=直接可用的公益助听产品，是最易落地、最"即拿即用"的一件。

04 芳莲 — 独居长辈不打扰守护（相邻参考）

芳莲守护助手硬件交互 + 社会公益 · IoT 传感器四端闭环
真实 ESP32+TDengine 制造业相关度弱 相邻参考
作者
李佩恒，数据库背景，江浙沪高端养老院实时看护系统建设经验
形态
无感传感器 + 微信小程序 + Web 后台 + TDengine 时序库 + 云服务器
传感器
药盒干簧管、水杯压力垫、床头平安按钮，ESP32 Hub，2 秒上报
发展阶段
初赛跑通核心链路；复赛做成多场景、四端闭环、可交付真实家庭

核心设计（精准）

  • 原则："关心要有边界"——不打扰、无感、零操作；老人照常生活，家属微信里看状态。
  • 闭环：硬件烧录 → heartbeat/事件上报 → 数据库记录 + Web 后台展示 → 微信小程序提醒。
  • 动机：奶奶叫芳莲；反对用摄像头"像宠物一样被监看"，选更温和的传感器路径。
  • 价值定位：低成本替代每年大几十万的养老院看护数据库方案；不依赖老人用智能手机。
80%
复现概率：软件闭环 ~80% / 含真实硬件部署 ~45%Web 后台 + 小程序 + TDengine + 云端事件管道可复刻；真实 ESP32+传感器焊接部署需买件+接线（我们无硬件，可用模拟事件注入替代软件闭环）。
价值：社会价值（不打扰养老监护），低成本替代高端方案。复刻价值=完整 IoT 产品参考，但偏离"科技工业制造"主线，列为相邻参考。若做养老方向值得复刻。

复现概率与价值汇总

作品复现概率最大瓶颈价值类型复刻优先级
词元开物软件 75% / 含雕刻 25%真实 PCB 雕刻机（无设备）概念/商业极高中（需 EDA+硬件）
开源太空~92%几乎无（公开数据+标准算法）科普/教学/国产替代高
听到鸟~90%WDRC/NAL-NL2 精度调优需声学知识公益/即拿即用高
芳莲软件 80% / 硬件 45%真实 ESP32 焊接部署社会/IoT 参考低（偏离制造主线）
结论：四件里开源太空（92%）与听到鸟（90%）复现概率最高——前者纯软件+公开 TLE/标准 SGP4+Three.js，后者纯前端 Web Audio 无硬件依赖，都是"写代码就能跑"的 web 应用，我们可直接复刻。

词元开物概念最性感但复现最卡硬件——软件 IDE 层 75% 可复刻，端到端"雕出真实板"需真实 CNC 雕刻机（我们无），概率跌到 25%。芳莲软件闭环 80% 可复刻，但真实传感器焊接部署需买件，且制造业相关度弱，列为相邻。

价值排序：词元开物（商业/概念）> 开源太空（科普/国产替代）≈ 听到鸟（公益/即用）> 芳莲（养老 IoT 参考）。

若我们动手：优先复刻开源太空（航天科普 web，零门槛高价值）与听到鸟（公益助听 PWA，即拿即用）；词元开物只做软件 IDE 原型；芳莲按需（养老方向）再做。
