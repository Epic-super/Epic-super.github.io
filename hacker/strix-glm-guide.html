1. Strix 平台简介

Strix 是一款开源 AI 渗透测试工具，由 Strix AI 团队全职维护，GitHub Stars 超过 58.7k，是安全工具品类最受欢迎的项目之一。

核心特点

• 不扫描，真攻击：不是传统扫描器报一堆误报，而是真的写 PoC 去验证漏洞，能打穿的才写进报告。
• 一条命令启动：npx @usestrix/strix start -u https://your-app.com -r /path/to/repo
• Docker 沙箱：攻击在容器内执行，不影响宿主机。
• CI/CD 友好：可直接集成到 GitHub Actions，每个 PR 自动跑安全测试。
• 自动修复：不仅能发现漏洞，还能直接生成修复 PR。

快速开始

# 方式1：npx 一键启动
npx @usestrix/strix setup
npx @usestrix/strix start -u https://target-app.com -r ./your-code

# 方式2：Docker
docker run -it --rm usestrix/strix:latest start -u https://target-app.com

5.3 GitHub Actions 集成

name: Security Scan with Strix
on:
  pull_request:
    branches: [main]
  schedule:
    - cron: '0 2 * * *'   # 每天凌晨 2 点（低谷时段）
jobs:
  strix-scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run Strix
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ZHIPU_API_KEY }}
          ANTHROPIC_BASE_URL: https://open.bigmodel.cn/api/paas/v4
          ANTHROPIC_MODEL: glm-5.3-flash
        run: |
          if [ "${{ github.event_name }}" = "pull_request" ]; then
            npx @usestrix/strix start -u ${{ secrets.TARGET_URL }} -r . --diff-only
          else
            npx @usestrix/strix start -u ${{ secrets.TARGET_URL }} -r . --full-scan
          fi

6. 注意事项

6.1 法律合规 重要

• 只测自己拥有的系统或有书面授权的目标
• 用 Docker 沙箱隔离，防止误伤生产环境
• 保留所有测试记录和授权证明
• 未授权测试属于违法行为

6.2 API 使用限制

速率限制（个人账号通常 10–50 QPS）、上下文 1M tokens（超出截断）、并发限制、API 调用费通常不退款。

6.3 模型能力边界

• MoE 模型：320B 总参数但仅激活 18B，复杂推理可能不如 GLM-5.3
• 速度较慢：约 49 tokens/sec（GLM-5.3 为 86）
• 长文本生成耗时：4000 token 约 82 秒
• 原生支持图像/视频，但 Strix 主要基于文本交互

6.4 成本控制

监控 API 用量、设置预算告警、错峰运行、固定 system prompt 提高缓存命中率（可降本 20–30%）。

6.5 技术兼容性

Strix 兼容智谱 OpenAI 格式；建议开启流式输出降低首 token 延迟感知。

7. 省钱技巧

• 错峰：配合 Coding Plan 非高峰时段 5 折（0 2 * * * npx @usestrix/strix start ...）
• 增量测试：PR 触发 --diff-only（成本减半），合并后 --full-scan
• 缓存优化：保持 system prompt 稳定，不要把时间戳/用户 ID 插在开头
• 批量任务：用 Batch API 五折
• 套餐选择：每周 1–2 次→按量付费；每天 1–3 次→Lite；每天 5–10 次→Pro；CI 全集成→Max

8. 常见问题

Q：GLM-5.3-Flash 和 DeepSeek V4-Flash 哪个好？
A：GLM-5.3-Flash 综合能力更强（AA 57 vs ~40）且更便宜（限时 ¥0.8/次 vs ¥3–15/次）；但 DeepSeek 上下文更长（1.3M）、无峰谷定价。推荐 GLM-5.3-Flash，9.9 前最划算。

Q：9 月 9 日后涨价多少？
A：从 $0.075/$0.25 涨到 $0.15/$0.50，翻倍；但仍比 DeepSeek 便宜且能力更强。

Q：Strix 支持智谱 API 吗？
A：支持。改 ANTHROPIC_BASE_URL 与 ANTHROPIC_API_KEY 即可。

Q：运行失败怎么办？
A：① 查 Key 有效性与余额；② 确认能访问 open.bigmodel.cn；③ npx @usestrix/strix logs；④ 降并发避 QPS 限制；⑤ 用 curl 测 API 连通性。
