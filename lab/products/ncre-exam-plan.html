0. 重要边界声明（务必先读）

⚠️ NCRE 信息安全 ≠ CTF / 渗透测试
  • 考核定位：NCRE 三级/四级信息安全考查的是信息安全基础理论体系 + 安全工程设计与综合防护方案（理论 + 设计 + 方案论证），属于防御、合规、架构视角。
  • 不考：漏洞利用（exploit）、渗透测试流程、CTF 夺旗（pwn / RE / web 解题）、靶机打点、提权横向。
  • 你的兴趣落点：你此前表达过 CTF/渗透实操兴趣，这只能作为"理解安全威胁的辅助直觉"，备考务必切换为防御/合规/理论视角，否则会把精力投入三级、四级都不考的攻击技术细节，事倍功半。
  • 实操导向建议：想真正练手打比赛，走通用学习路线（CTFHub / PicoCTF / PortSwigger Academy / Hack The Box），与 NCRE 取证实务分开进行。

3.2 核心考点精讲（高频 + 易错）

密码学（分值最高，必须吃透）

  • 对称加密：DES 分组 64 位/有效密钥 56 位；3DES 三密钥；AES 分组 128 位/密钥 128/192/256；RC4 是流密码。
  • 非对称加密：RSA=大整数因子分解；ECC=椭圆曲线离散对数；DH/ElGamal=离散对数。非对称速度慢，仅用于密钥交换/签名，不加密大量数据。
  • 哈希：MD5=128 位(已不安全)；SHA-1=160 位(不推荐)；SHA-256=256 位。单向、定长、抗碰撞。
  • 数字签名：发送方私钥签、公钥验，实现不可否认+完整性；不保证机密性（需再加密）。
  • 易错：混淆"加密=签名"；混淆对称/非对称场景；误记 DES/AES 分组长度。

网络安全设备

  • 防火墙三类：包过滤(网络/传输层、快、不查内容)、状态检测(维护连接表、性能安全均衡、最常用)、应用代理(应用层、安全高、慢)。防火墙防不了内部威胁与病毒。
  • VPN：IPSec(网络层，站点到站点)、SSL VPN(远程接入，免客户端)。
  • IDS(旁路、只告警不阻断) vs IPS(串联、可阻断)；HIDS/HIPS 主机型。

系统安全 / 应用安全 / 法规

  • 访问控制三模型：DAC(自主可转授)、MAC(强制，如 BLP)、RBAC(基于角色，企业最常用)。
  • SQL 注入根因是字符串拼接，防护靠参数化查询/预编译；XSS 靠输出编码+CSP；CSRF 靠 Token。
  • 等保2.0 五级：①自主保护 ②指导保护 ③监督保护 ④强制保护 ⑤专控保护；三级及以上每年测评。
  • ISO/IEC 27001 核心是 PDCA。易错：混淆各法生效时间/管辖。

3.3 典型真题

真题1（密码学·单选）：RSA 算法基于的数学难题是？A.离散对数 B.大整数因子分解 C.椭圆曲线离散对数 D.背包。— 答案 B。

真题2（防火墙·单选）：状态检测防火墙能跟踪连接状态，安全性与性能较均衡（正确项）。包过滤在网络层、应用代理在应用层且慢、防火墙不能防内部与病毒。

真题3（等保·单选）：等保2.0 共 五级，第三级称监督保护级。注意第四级是强制保护级（易混）。

真题4（综应·防火墙规则）：仅放 Web(80/443)、禁外部直连 DB、禁内网访问危险 IP、默认拒绝。体现默认拒绝 / 最小权限 / DMZ 隔离三原则，规则按序首匹配生效。

4.2 核心考点精讲（四级 vs 三级深化 + 易错）

  • 从"是什么"到"怎么设计"：三级记等保五级，四级给定场景设计等保三级建设整改方案。
  • 新增信息安全工程：SSE-CMM 五能力等级(1非正规→5持续改进)、ISSE 五步(发掘需求→定义目标→设计架构→开发设计→集成)。易错：混淆 SSE-CMM / SW-CMM / ISO27001 PDCA / 等保级别。
  • 新增密码应用与密评：四层面(物理/网络/设备/应用)；国密 SM2(非对称/签名/ECC)、SM3(哈希)、SM4(对称)、SM9(标识)、SM1(对称/硬件不公开)。易错：SM3当对称、SM1当公开、SM2 替代 RSA 合规。
  • 新增等保全流程：五环节定级→备案→建设整改→测评→监督检查；二维定级(客体×程度)；云/物联网/大数据/工控特殊规则。
  • 新增数据安全治理：分类分级(一般/重要/核心)、全生命周期六环节、个保法(告知-同意/最小必要)、数安法(出境)。
  • 新增运维应急：RTO/RPO 与备份频率关系；响应六阶段(准备→检测→遏制→根除→恢复→跟踪)；BCP/DRP。
  • 高频易错：等保2.0 是技术+管理双要求；定级二维表必熟；密评四层面≠等保测评；SSE-CMM 等级≠等保级别；响应阶段顺序不可颠倒；可用性公式 A=MTBF/(MTBF+MTTR)。

4.3 典型真题（四级综合设计风格）

例一·综合设计：某市"政务服务平台"定级等保三级，设计建设整改方案（安全域划分 / 边界设备 / 密码应用 / 制度清单≥4类）。要点：安全域=接入区/DMZ/核心业务区/安全管理区(SOC)/数据区；设备=防火墙+IPS+抗DDoS+堡垒机+数据库审计+WAF+态势感知；密码=链路SM4 VPN、传输SM2/SM3、存储SM4、KMS统一管理；制度=建设/运维/人员/应急/密码管理。关键：技术+管理双维度齐全 + 纵深防御。

例二·计算：每日0点全量、每小时增量；最大丢1小时数据、最大停机4小时。求 RPO/RTO。答：RPO=1小时(=增量周期)，RTO=4小时；策略=全量+hourly增量，先全量再顺序增量，辅异地容灾。RPO 定备份频率，RTO 定恢复方案。

例三·方案论证：原 RSA-2048+SHA-1 需过密评，指出不合规并整改。答：SHA-1 不安全改 SM3/SHA-256；关基或等保三级以上优先 SM2 替代 RSA；密钥纳合规 KMS 禁硬编码；落实四层面密码应用。

4.7 三级 → 四级 晋级路径与先修硬规则

硬规则：取证四级必须先（或同期有效）取得三级「信息安全技术」证；四级过、三级未过 → 不发证，成绩保留，待三级通过后一并核发。
路径：阶段一(3–4月)过三级 → 衔接周(1–2周)视角切换 → 阶段二(3–4月)过四级 → 两段成绩有效后四级证随三级证一并核发。
岗位图谱：等保方案→等保咨询师/合规工程师；密码应用→密码应用工程师/密评；安全架构→安全架构师；应急灾备→安全运维/SOC；安全测评→测评师(需资质)。
