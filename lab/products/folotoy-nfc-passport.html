快速开始

cd backend
npm install
npm run init-db
npm start          # → http://localhost:3000（后台 /web）

设备端模拟：cd device && npm i ws && node server.js（WS :8080）；NFC 实测：device/nfc_test.py（pyserial，COM3）。固件：firmware/ ESP-IDF，build.cmd 构建。详细说明见 试验台说明.md。
