这是干什么的

一个生产级番剧门户，参考 AniList / bangumi 的信息架构：

  • 首页 Hero 大图 + 当季热播 + 人气榜单
  • 浏览 / 排行 / 搜索，含季度切换与分页
  • 番剧详情（评分 / 类型 / 工作室 / 角色 / 推荐）
  • 本周放送时间表（周一→周日）
  • HLS 播放（hls.js + Safari 原生回退）与收藏

怎么启动本地服务

这个页面只负责接入门户。Next.js 服务在另一个目录，它不在这里：

  • 源码目录：<本地路径>
  • 启动：cd /d <本地路径> 然后 npm run dev（默认 3000 端口）
  • 依赖已装好；服务未启动时本页显示降级说明而非空白
  • 番剧元数据需能访问 graphql.anilist.co，网络不通时首页会优雅降级为空态
① 启动 npm run dev（3000）→ ② 本页自动检测并嵌入→ ③ 首页选番 → 详情 → 播放→ ④ 播放页填 m3u8 源（按番剧记忆）
说明：门户源码为独立私有项目 anime-portal（Next.js 15），不随本公开站部署； 本页在服务可用时内嵌门户，不可用时降级为操作指引。仓库不内置任何视频直链， 默认仅载入公开 HLS 测试流，正式源由你在播放页填写或走苹果CMS 检索。
