# FoloToy NFC 试验台 · 精简说明

> 复刻 TRAE AI 创造力大赛决赛现场通行证玩法：FOLOTOY 八爪鱼硬件 + NFC 模块 → 现场打卡 → Token 发放 → 奖品兑换。
> 本包 = 完整可运行代码 + 硬件软件试验台。原 README 见同目录 [README.md](README.md)。

## 一、系统架构

```
┌─────────────────┐   WiFi/MQTT    ┌──────────────────┐
│  FOLOTOY 设备    │ ◄────────────► │  Node.js 后端     │
│  (NFC 打卡交互)  │                │  (API + 业务逻辑) │
└─────────────────┘                └──────────────────┘
         ▲                                │
         │ NFC 触碰                        │ SQLite
┌─────────────────┐               ┌──────────────────┐
│  NFC 展位标签    │               │  本地数据库        │
│  (固定打卡点)    │               │  设备/打卡/兑换     │
└─────────────────┘               └──────────────────┘
```

## 二、核心功能

- NFC 现场打卡并发放 Token（同一设备/同一展位每日限次）
- Token 余额查询 + 交易流水
- 奖品兑换 + 库存管理
- 设备端语音反馈 + 灯光提示（固件）
- 管理后台统计（Web 控制台）

## 三、硬件清单

| 硬件 | 说明 |
|---|---|
| FOLOTOY 八爪鱼 标准版/Mini | 主控 |
| PN532 / PN7150 NFC 模块 | 读写 |
| NFC 标签 NTAG213/215 | 展位打卡点 |
| Type-C 线 / 杜邦线 / 面包板 | 接线 |
| 可选：外壳 / RGB 灯带 / 小喇叭 | 扩展 |

## 四、快速开始

**方式一：本地 Node 直接跑（最快）**

```bash
cd backend
npm install
npm run init-db        # 建库
npm start              # 起服务 → http://localhost:3000
# 管理后台: http://localhost:3000/web
```

**方式二：Docker 一键**

```bash
# Windows
deploy.bat your-admin-api-key
# Linux/macOS
./deploy.sh your-admin-api-key
# 后台: http://localhost/web
```

**方式三：演示数据 + 测试**

```bash
cd backend
npm run init-db
node src/scripts/seed-demo-data.js   # 3 设备 + 4 展位 + 4 奖品
npm test                              # Jest 全流程测试
node src/scripts/run-demo.js          # 完整用户旅程演示
```

## 五、API 速查（基础路径 http://localhost:3000/api）

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | /api/health | 健康检查 |
| POST | /api/nfc/checkin | 打卡 `{device_id, tag_uid}` |
| GET | /api/token/balance/:device | 余额查询 |
| GET | /api/rewards | 奖品列表 |
| POST | /api/rewards/redeem | 兑换 `{device_id, reward_id}` |
| * | /api/admin/* | 管理（需 `Authorization: Bearer <API_KEY>`）|
| GET | /web | 管理后台页面 |

统一返回 `{success, data}` / `{error}`；管理接口带 Bearer 认证；后端 CORS 全开（试验台页面可跨域直连）。

## 六、设备端对接（三选一）

- **HTTP**：curl POST /api/nfc/checkin（见 README 示例）
- **WebSocket**：`ws://localhost:8080`，发 `{type:"nfc_detected", tag_uid}`
- **MQTT**：订阅 `folotoy/nfc/{device_id}/response`，发布到 `.../request`（mosquitto 配置在 `mosquitto/`）

## 七、硬件软件试验台

- **Web 试验台页**：`../folotoy-nfc-passport.html`（本仓库 lab/products）——填 API_BASE（默认 http://localhost:3000）即可在线测打卡/余额/奖品/兑换，无需写码
- **设备端模拟**：`device/server.js`（Node WS 模拟设备，npm i ws 后 `node server.js`）+ `device/nfc_test.py`（串口 AT 实测，需 pyserial）
- **固件**：`firmware/` ESP-IDF 工程（components：nfc_manager / passport_controller / offline_cache / ble_provisioning / ota_manager / hal / network_manager / at_command_handler），`build.cmd` 构建

