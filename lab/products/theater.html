这是干什么的

一个影视聚合客户端，Electron 桌面端与 Web 共用同一套代码：

  • 8 个页面：首页 / 发现 / 详情 / 播放 / 收藏 / 最近 / 下载 / 设置
  • 苹果CMS 多源渐进聚合（约 45 个可用源，运行时探活），去重 + 分批并发、首批够用即停，避免连接风暴
  • 自研播放器：自定义控制栏、字幕、倍速、画中画、键盘快捷键
  • 时间级续播（按剧集记忆进度）+ 网络 / 媒体错误分级自愈
  • 收藏、观看历史、下载队列本地持久化

怎么启动本地服务

本页只负责接入剧场。源码在另一个目录，它不在这里：

  • 源码目录：<本地路径>
  • 桌面端（主形态）：npm run electron　同时拉起 Vite + Electron 窗口
  • 仅 Web 版（本页嵌入用）：npm run dev　端口 5173
  • 依赖已装好；服务未启动时本页显示降级说明而非空白
端口提醒：剧场的 Web 服务是 5173。此前它默认用 3000， 会与开机自启的「番剧门户」撞车 —— 启动器只判断「端口有没有被监听」， 可能把番剧门户当成剧场加载进窗口。现已改为 5173，并加了页面身份校验兜底。
① 启动 npm run dev（5173）→ ② 本页自动检测并嵌入→ ③ 首页 / 发现选片→ ④ 详情选线路 → 播放 / 续播
说明：剧场源码为独立私有项目 free-theater（Electron + Vite + React），不随本公开站部署； 本页在服务可用时内嵌 Web 版，不可用时降级为操作指引。仓库不内置任何视频直链， 片源来自公开 CMS 源站检索；开发模式下相关请求经 /cms-proxy 转发， 也可改写走番剧门户的 /api/cms（服务端多源聚合，无 CORS 限制）。
