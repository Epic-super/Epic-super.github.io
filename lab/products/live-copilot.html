这是干什么的

给视频号直播（或任何在电脑上出声的直播）做实时字幕 + 自动纪要：

  • 浏览器抓系统音频（不需要 ffmpeg / 虚拟声卡）
  • 本机 faster-whisper 实时转写，比直播快 4~6 倍
  • 自动切章、抽要点、挑金句、列行动项
  • 一键导出 PPT / Markdown / SRT / JSON

怎么启动本地服务

这个页面只负责接入工作台。转写等重活由你在本机运行的 Python 服务承担，它不在这里：

  • 确保已启动：<本地路径>（端口 8770）
  • 或命令行：python server.py --port 8770
  • 服务未启动时，本页会显示降级说明而不是空白
① 启动本地服务 8770→ ② 点「打开直播工作台」→ ③ 开始采集 → 抓整个屏幕 + 分享系统音频→ ④ 停止并自动生成纪要 → 导出 PPT / MD
说明：转写与纪要引擎为本地 Python 服务（tools/live-copilot/），不随本公开站部署； 本页在服务可用时内嵌工作台，不可用时降级为操作指引。音频全程不出本机。
