① 作品简介

是什么结合 AI 大模型（火山方舟）的 Web 应用：输入任意数学知识点，AI 自动生成对应的 3D 可视化图形。
面向谁数学爱好者、学生、教育工作者，以及对 3D 可视化与数学美学感兴趣的所有人。
作者背景后端开发工程师（Python / Go），不懂前端与 Three.js；本项目 100% 代码由 TRAE 生成，作者扮演「产品经理 + 测试」角色。
体验地址https://traeai.liufei.fun/math-beauty/

② 三大核心功能

功能一 · AI 一键生成

首页输入任意数学概念，或从 20 个预设模板标签中选择，AI 自动选合适可视化类型（共 7 种），并生成完整 3D 渲染配置。

功能二 · 沉浸式查看器

支持拖拽旋转、滚轮缩放、自动旋转、全屏。左下信息面板展示分类/标题/描述/时间；可看数学公式（KaTeX 渲染 LaTeX）与 AI 生成的测试题。

功能三 · 历史与分类

所有结果自动保存，按技术领域（几何 / 拓扑 / 分析 / 代数 / 混沌 / 分形等）自动分类，支持搜索与排序。

7 种可视化类型

参数曲面 · 混沌吸引子 · 空间曲线 · 递归分形 · 三角函数教学 · 线框结构 · DNA 双螺旋

预设模板示例：莫比乌斯环、洛伦兹吸引子、克莱因瓶、DNA 双螺旋、各类分形与三角函数曲面等共 20 个。

③ 创作思路

灵感来源对数学「几何之美」着迷——莫比乌斯环的拓扑奇妙、洛伦兹吸引子的混沌优雅、分形的无限自相似；但多数人对「数学之美」只停留在课本枯燥公式与二维示意图。
想解决的痛点① 数学可视化门槛极高（需同时掌握数学建模 + Three.js/WebGL + 着色器）；② 数学教育缺乏直观体验；③ 没有「输入概念就出图」的工具（GeoGebra/Desmos 仍需手动输方程）。
为何做这个方向AI 最大价值之一是「降低门槛」——用自然语言输入概念，AI 翻译成精确 3D 渲染参数，让普通人也能「看见」数学。

④ 技术栈

前端React + TypeScript + Three.js（含自定义 GLSL 着色器、粒子系统、混沌吸引子）
后端FastAPI + SQLite，通过 Docker Compose 一键部署
AI火山方舟（Volcano Ark）大模型，负责把数学概念转换为 3D 渲染配置（JSON）
其他KaTeX 渲染 LaTeX 公式、Framer Motion 动画控制

⑤ TRAE 实践过程

全程使用 TRAE IDE 开发。作者开发方式：想清楚功能长什么样 → 自然语言描述给 TRAE → 跑起来看效果 → 不对就继续描述调整。示例：描述「两条反向螺旋骨架、横杆连碱基对、球体节点、颜色交替」即生成完整 DNAHelix.tsx。

⑥ 踩坑复盘

坑 1 · AI 返回 JSON 格式不稳定

火山方舟偶尔返回缺右括号、尾部多逗号、字符串未转义引号。作者写多层容错 _repair_json（提取 markdown 代码块、定位最外层 {}、修常见格式错误），大幅提升成功率。

坑 2 · Three.js 渲染性能

首页背景同时跑粒子系统 + 形状轮播（5 种 GLSL 着色器）在低性能设备卡顿。TRAE 协助优化粒子数、降着色器复杂度，并用 Framer Motion 在页面切换时及时释放渲染资源。

坑 3 · DNA 渲染与 AI 生成冲突

AI 有时给 DNA 概念生成 structure 而非 dna 类型。后端加 _post_process_config，检测关键词（DNA / 双螺旋 / 碱基对）后强制切到 dna 类型并清理干扰参数。

⑦ 经验总结

  • 清楚描述需求是高效协作关键：越具体，TRAE 生成质量越高（如描述 DNA 时要说清几何体、颜色交替、动画控制）。
  • 善用迭代：第一版不完美，多轮对话逐步打磨到满意。
  • 不怕不懂的技术栈：后端工程师也能靠 TRAE「翻译」需求跨过 Three.js / GLSL 盲区。
  • 保持可维护性：虽是 AI 生成代码，仍要求清晰文件结构、完整 TypeScript 类型、合理组件拆分。

⑧ 为何放进「空间训练」板块

数学之美本质是把抽象数学概念转化为可旋转、可缩放、可全屏观察的 3D 实体——这恰好训练「空间想象 / 空间感知」能力：拓扑结构（莫比乌斯环、克莱因瓶）、参数曲面、空间曲线、分形自相似，都是立体几何与空间直觉的极佳素材。与本站「空间思维训练 / 心理旋转 / 脑力训练」同属「用可视化锻炼空间认知」范畴，故归入此板块作为开放外部资源。
