这是干什么的

把脑中一闪而过的想法、收藏的资料、正在做的任务和零散笔记，统一交给一个可检索、会关联、能总结的个人信息管家：

  • 自动识别想法 / 资料 / 待办 / 笔记
  • 提取摘要、标签、重点与待办事项
  • 关键词检索、基于已有内容智能问答
  • 阶段总结、主题趋势与后续行动建议

怎么启动本地服务

本页只负责接入工作台，数据和模型调用由本机 Python 服务承担：

  • 双击 <本地路径>
  • 首次运行复制 .env.example 为 .env，填入 OpenAI 兼容 API Key
  • 服务地址：http://127.0.0.1:8200
  • 未启动时，本页会保留这份操作指引，不会出现空白死链
① 启动本地服务 8200→② 点「打开信息管家」→③ 随手记录→④ 问答 / 总结 / 行动
说明：网关页进入公开站，实际工作台由 tools/personal-info-agent/ 本地服务提供；数据库与大模型密钥不进入公开站。服务在线时自动内嵌，不在线时降级为操作指引。
