🤖 欢迎来到塔台智能体
这是一个真正会调用工具、有长期记忆的智能体：能帮你跳转站内页面、查工作台版本与变更、记住你交代的事、做计算、报时间——既能在本地 127.0.0.1:8080 用，也能在公开站 epic-super.github.io 用。

开始只需三步：① 点右上角「设置」→ 选预设（DeepSeek 或 StepFun）→ ② 粘贴你自己的 API Key（只存在你本机浏览器的 localStorage，不上传不入库）→ ③ 保存，开聊。
没有账号？DeepSeek 在 platform.deepseek.com 注册即送额度。Key 只走你浏览器到模型商的直连，本站服务器经手不到它。
