🌊 Vibe Coding 的边界

Karpathy 2025 年提出的词：全情投入 AI 的输出、拥抱扩散式探索、几乎忘记代码本身的存在。它很强，但只在特定象限强。

✅ 放心 Vibe 的地方

原型与 demo / 一次性脚本 / 个人工具 / 探索陌生 API / UI 氛围调优 / 让 AI 写测试用例再人工过一遍。判断句：坏了的代价 < 10 分钟重做。

⛔ 别 Vibe 的地方

涉及钱与鉴权的代码 / 数据库迁移 / 并发与锁 / 密钥处理 / 你看不懂却要维护的核心逻辑。判断句：出事的代价是信誉或资金。

🧭 三种流派

氛围流：一句话让 AI 自由发挥（原型最快）；结对流：AI 出方案你逐段审（默认推荐）；规格流：先写验收标准与接口契约再让 AI 实现（生产级）。

⚖️ 唯一铁律

AI 生成的每一行，你要能向另一个人解释它为什么对。解释不了 = 技术债 +1。Vibe 加速的是打字，不是理解。

🧭 提示词模式库 · 八个可复用招式
