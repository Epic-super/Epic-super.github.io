TRAE 2026 航空方向作品调研

聚焦「航空制造 / 航空设计」细分 · 2026-08-24 整理 · 来源：论坛初赛专区 + 决赛报道
核心结论： 经 4 轮定向检索（飞机/机翼/气动/CFD/航空发动机/复材/飞机制造/工装 + 飞行汽车/eVTOL/无人机/低空经济）， 2026 届大赛没有任何「航空（飞机）制造 / 航空设计」硬核作品。没有出现气动外形设计、CFD 流场、机翼/结构优化、航空发动机、复材铺层、总装工装这类内容。 能检索到的"航空相关"全部是航空应用 / 飞行器仿真 / 无人机演示类，且清一色是零基础参赛者用 TRAE Work 生成的 Demo，均未触及"设计或制造飞机"本身。
概念澄清 你此前在另一台设备沉淀的 「开源太空 · 卫星守望者」属于「航天」（卫星轨道），不是「航空」（飞机/飞行器）。本页只谈航空（大气层内飞行器）。两者在产业里分属不同赛道，请勿混淆进同一复现清单。
航空相邻作品（4 件 · 均非航空制造/设计）

① 净滩鹰 Aerial Cleanup System 硬件交互赛道

Web 端 3D 实时演示 Demo · 海边沙滩垃圾清理无人机概念

形态与功能

用 Three.js 实时渲染一座低多边形海边沙滩场景（天空/远山/海浪/礁石/椰林/木栈道/长椅/垃圾桶/可拾取易拉罐与塑料瓶）。场景中央一台搭载机械爪的四旋翼无人机，可拖拽旋转、滚轮缩放，演示从地面拾取垃圾的动画。本质是"硬件概念的可视化演示"，非真机控制。

真实度边界

纯前端 3D 演示。作者自述"交互界面渲染会出 bug，再用图片告诉 Trae 想要什么效果，多轮调试达成"。无真实飞行控制、无视觉抓取算法、无垃圾识别模型、无真实海洋数据，是四件里最"概念"的一件。

演示 100%
复现概率（作品本身）：~90% — 纯前端 Three.js 场景 + 无人机模型 + 机械爪动画可完整复刻（还能换更精的 GLTF 模型）。
与"航空制造/设计"距离：极远 — 它做的是"无人机应用场景演示"，连无人机本体的气动/结构都没设计。
价值：作为 3D 科普/概念演示模板可借鉴；对航空制造无参考价值。

② 苍穹降临：三维交通秩序推演沙盒 社会服务赛道

网页三维交通推演 · 未来城市空中交通（eVTOL / 飞行汽车）

形态与功能

单文件 HTML，双击即跑。演示未来城市空中交通在"无调度"与"有调度"两种状态的差异：① 混沌推演——300 架飞行器自由飞行，碰撞/坠毁/混乱；② 苍穹调度——一键激活算法，所有飞行器切换至三层有序航道，零碰撞。③ 实时数据面板：在网飞行器数、碰撞次数、实时碰撞风险率。

真实度边界

作者直接把完整源码贴进帖子（可复制保存为 苍穹降临.html 运行）。调度算法为演示性规则（三层航道划分 + 冲突规避），非真实空管系统、无真实飞行器动力学、无三维城市 GIS。是"城市空中交通 UAM"概念的可视化论证。

100% 开源
复现概率（作品本身）：~95% — 源码已公开，纯前端粒子/实体 + 调度规则，可直接跑并二次开发。
与"航空制造/设计"距离：远 — 属于"空域交通管理仿真"，飞行器只是抽象实体，不涉及飞机设计。
价值：UAM/低空空管科普演示的极佳模板；复刻门槛最低。

③ 小飞伴 — 飞行员认知恢复系统 生活娱乐/学习

HTML 交互 Demo · 民航飞行员落地后认知恢复 App

形态与功能

可交互 HTML，5 屏流程：AI 评估 → 量化指标 → 认知卸载动画 → 入睡安排 → 早安恢复。输入飞行时长/时区跨越/夜航/连续执勤天数，AI 算三大量化指标（认知电量 / 睡眠债务 / 时差错位），自动匹配四大恢复模块（认知卸载 / 光照恢复 / 决策疲劳恢复 / 身体恢复训练），用孩子声音陪伴执行。

真实度边界

基于航空医学理论（昼夜节律、认知科学、决策疲劳、人体工学）。"AI 计算"为前端脚本化公式（非真实 LLM 推理），数据来自 FAA/DLR 等公开研究报告的理论映射。父子共创（10 岁孩子出核心洞察 + 父亲用 TRAE 实现）。是"航空心理健康"应用，与制造/设计无关。

~95%
复现概率（作品本身）：~95% — 纯前端 5 屏 + 动画，可 1:1 复刻，还能接真实 LLM 反超"模拟评估"。
与"航空制造/设计"距离：远（但航空场景最贴） — 唯一直接面向"民航飞行员"的作品，但做的是健康恢复 App。
价值：航空人因/职业健康方向的产品参考；对航空制造无参考价值。

④ 低空飞行服务平台 · 无人机供需撮合 社会服务赛道

微信小程序 · 无人机服务（航拍/巡检/植保）供需撮合

形态与功能

微信小程序完整方案：① 任务发布 & 接单大厅（雇主填服务类型/地点/预算/时间，飞手按类型+距离筛选一键联系）；② 订单管理（待接单/待确认/进行中/已完成/已取消 + 双方评价）；③ 飞手展示体系（LBS 距离排序、机型/技能/历史评分、CAAC 证书核验）。作者是低空经济市场人员，用手机端 TRAE Work 生成。

真实度边界

撮合逻辑 + LBS + 订单状态机是真实可跑的，但无真实飞手/雇主入驻、无真实 CAAC 证书 API 对接、无支付闭环，是 Demo 级平台原型。属于"低空经济运营工具"，不是航空制造。

~80%
复现概率（作品本身）：~80% — 小程序框架 + 撮合逻辑可复刻；需微信开发者工具与真实 LBS/证书数据源增强。
与"航空制造/设计"距离：远 — 是"用无人机做生意"的平台，无人机只是被调度的工具。
价值：低空经济撮合平台的参考架构；对航空制造无参考价值。

为什么没有硬核「航空制造/设计」作品
① 赛事定位：面向全民、零门槛，"用 TRAE Work 几分钟生成 Demo"，参赛者多为非专业背景，产出以 App/小程序/网页演示为主。
② 领域门槛：真实航空制造/设计需要气动 CFD（如 OpenFOAM）、结构有限元（如 NASTRAN）、复材铺层、适航认证等重型工程栈与专业数据，远超一个周末 Demo 的承载力。
③ 数据可得性：机翼外形、风洞数据、发动机性能曲线等要么涉密、要么需商业授权，个人参赛者拿不到。
④ 对比你之前沉淀的工业类：半导体设备/汽车检具/数据立方虽也是工业，但"工业软件/监控/调度"尚可纯前端或桌面端 Demo 化；而"造飞机/设计飞机"的硬核部分无法被轻量 Demo 化，所以本届直接真空。
